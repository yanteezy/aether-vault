# Aether — інструкція для розробника

> Англійська сторінка проєкту — у [README.md](../README.md).

Просторовий нотатник на нескінченному полотні для macOS і Windows.
Tauri 2 + React 19 + TypeScript + Vite; дизайн у стилі Apple (матове скло, spring-анімації).

## Що потрібно встановити

- [Node.js](https://nodejs.org) 20+ (разом із npm)
- [Rust](https://rustup.rs) (stable)
- macOS: Xcode Command Line Tools (`xcode-select --install`)
- Windows: Microsoft C++ Build Tools і WebView2 (зазвичай уже є у Windows 10/11)

## Запуск для розробки

```bash
npm install
npm run app:dev     # вікно застосунку з гарячим перезавантаженням
npm run dev         # або лише веб-версія в браузері: http://localhost:1420
```

## Інсталятори та онлайн-оновлення

Інсталятори збирає GitHub (macOS `.dmg` для Intel і Apple Silicon, Windows `.exe`).
Встановлені копії Aether самі перевіряють оновлення під час запуску і в
«Налаштування → Про застосунок → Перевірити».

### Один раз: підготовка GitHub

1. Створіть **публічний** репозиторій на GitHub і завантажте туди цю теку
   (з приватного репозиторію застосунок не зможе завантажити оновлення).
2. Repository → Settings → Secrets and variables → Actions → **New repository secret**:
   - `TAURI_SIGNING_PRIVATE_KEY` — увесь вміст файлу `~/.tauri/aether.key`;
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — пароль ключа (якщо пароля немає — не створюйте).
3. Публічний ключ уже записаний у `src-tauri/tauri.conf.json` → `plugins.updater.pubkey`.
   Адресу оновлень (`__REPO__`) GitHub підставляє сам під час збірки.

> Приватний ключ нікому не передавайте і не кладіть у репозиторій.
> Якщо його втратити — встановлені копії більше не зможуть оновлюватися.

### Як випустити нову версію

1. Змініть версію в `package.json` (наприклад `0.2.12` → `0.2.13`). `tauri.conf.json` бере її звідти.
2. Опишіть зміни в `RELEASE_NOTES.md` — цей текст користувачі побачать у вікні оновлення.
3. Відправте зміни й тег:
   ```bash
   git commit -am "Aether 0.2.13"
   git tag v0.2.13
   git push && git push origin v0.2.13
   ```
4. GitHub → Actions: збірка триває ~15–20 хв. Після неї в Releases з'явиться **чернетка** релізу
   з `.dmg`, `.exe`, файлами оновлення і `latest.json`.
5. Перевірте чернетку й натисніть **Publish release**. Відтепер встановлені копії
   побачать «Доступна версія 0.2.13».

Тег має збігатися з версією в `package.json`, інакше збірка зупиниться з підказкою.

### Перше встановлення (для вас і знайомих)

Посилання для завантаження: `https://github.com/<ваш-логін>/<репозиторій>/releases/latest`.

- **macOS**: відкрийте `.dmg`, перетягніть Aether у «Програми». Застосунок не підписаний Apple,
  тому при першому запуску macOS його заблокує: «Системні параметри → Конфіденційність і безпека →
  Все одно відкрити». Це потрібно лише один раз; оновлення далі ставляться без цього.
- **Windows**: запустіть `Aether_<версія>_x64-setup.exe`. Якщо з'явиться «Windows захистила ваш ПК» —
  «Докладніше» → «Все одно запустити». Права адміністратора не потрібні.

### Локальна збірка на Mac (необов'язково)

Оскільки інсталятор тепер підписує файли оновлення, перед збіркою передайте ключ:

```bash
export TAURI_SIGNING_PRIVATE_KEY="$(cat ~/.tauri/aether.key)"
export TAURI_SIGNING_PRIVATE_KEY_PASSWORD=""   # або ваш пароль
npm install
npm run app:build                              # → src-tauri/target/release/bundle/dmg/
```

У локальній збірці адреса оновлень лишається шаблонною, тож перевірка оновлень у ній
не працюватиме — для розповсюдження користуйтеся збірками з GitHub.

## Структура

- `src/App.tsx` — сховища (вкладки), налаштування, мова, splash
- `src/Workspace.tsx` — одне сховище: нотатки, зв'язки, малюнки, рамки, кнопки-теги, кругове меню
- `src/components/` — полотно (`CanvasBoard`), картки (`NoteCard`, `NoteMenu`), зв'язки, док (`CommandDock`),
  малювання (`Ink`, `InkToolbar`), рамки (`Frames`), кнопки-теги (`TagButtons`), пошук, налаштування, список нотаток
- `src/i18n/` — локалізація: `t('український рядок')`, англійські переклади в `en.ts`
- `src/data/guide.ts` — нотатки-посібник, що з'являються при першому запуску
- `src/settings/settings.ts` — налаштування, теми, сітка, гарячі клавіші
- `src/hooks/usePersistentState.ts` — збереження будь-якого стану в localStorage
- `src/styles/` — теми (Скло, Світла, Дошка детектива, Креслення, Монохром)
- `src-tauri/` — Rust-частина Tauri, іконки, конфіг вікна
- `src-tauri/installer/` — оформлення інсталяторів (фон `.dmg`, картинки `.exe`)
- `src/components/UpdateNotice.tsx` — онлайн-оновлення (перевірка, завантаження, перезапуск)
- `.github/workflows/release.yml` — збірка інсталяторів і релізів на GitHub

Дані нотаток зберігаються локально (localStorage вебв'ю), окремо для кожного сховища.

## Додати переклад рядка

1. У компоненті: `const tr = useT()` і `tr('Текст українською')`.
2. Додайте у `src/i18n/en.ts` рядок `'Текст українською': 'English text',`.
