# Aether — опис застосунку для консультації з дизайну

> Цей файл — контекст для розмови з Claude у звичайному чаті. Закиньте його в чат, додайте скриншот того місця,
> про яке питаєте, і поставте питання (шаблон — у кінці). Стан на версію 0.10.0.

---

## 1. Що це за застосунок

**Aether** — десктопний застосунок для нотаток (Windows, далі macOS) на Electron + TypeScript, без UI-бібліотек: увесь інтерфейс — власні компоненти й CSS.

- **Сумісний з Obsidian:** нотатки — звичайні файли Markdown (`.md`) у папці на диску («сховище»), полотна — файли JSON Canvas (`.canvas`). Ту саму папку можна відкрити в Obsidian, і навпаки. Плагіни спільноти Obsidian теж працюють.
- **Головна ідея:** живе **полотно** (нескінченна дошка з картками й зв'язками) поруч зі звичайним редактором нотаток. «Один запис — багато видів»: та сама нотатка — і текст у редакторі, і картка на полотні.
- **Мова інтерфейсу:** українська.
- **Для кого:** людина, що веде нотатки щодня годинами (робочий інструмент «на весь екран», а не швидка утиліта). Тому інтерфейс тихий, з акцентом на вмісті, з гарячими клавішами.
- **Claude-інтеграція:** вбудований MCP-сервер дає Claude Desktop / Claude Code **лише читати** сховище (нотатки, полотна, пошук, «що відкрито й виділено зараз»).

## 2. Візуальна мова — «Скло» (за мотивами Apple Liquid Glass, WWDC26)

Темна тема (світлої поки немає — це свідоме рішення, може змінитись).

### Принципи
- **Вміст — головний.** Скло лише на «хромі» (бічна панель, шапка, док, меню, діалоги, повідомлення). Картки полотна й текст — **непрозорі**, щоб нічого не просвічувало крізь текст.
- **Не класти скло на скло** (жодних прозорих меню поверх прозорих панелей без підкладки).
- **Рамка скла** — рівний світлий обідок 1 px (rgba 255,255,255,0.14) по краю; жодних «бліків» у куті.
- **Підсвітка курсором** — лише краї скляних елементів світлішають біля курсора; самі поверхні не сяють.
- **Концентричні радіуси:** радіус зовнішнього = радіус внутрішнього + відступ (панель 18 = кнопка 12 + відступ 6).
- Режим «Зменшити прозорість» (у налаштуваннях і за системним прапорцем) робить скло суцільним.

### Кольори
| Роль | Значення |
|---|---|
| Фон вікна | `#151a26` з двома розмитими плямами `#3b5b8f` (вгорі ліворуч) і `#5a3f7a` (внизу праворуч) |
| Скло панелей | `rgba(28,30,42,0.72)`, розмиття `blur(28px) saturate(190%)`; меню — `0.82` |
| Картка полотна | `rgb(37,40,51)` непрозора, рамка `rgba(255,255,255,0.12)`, радіус 14 px |
| Текст | основний `#f5f5f7`; приглушений `rgba(235,235,245,0.7)`; найслабший `rgba(235,235,245,0.62)` |
| Акцент (кнопки) | `#0a64d6` (наведення `#1a74e6`); акцентний текст / посилання `#6cb4ff` |
| Помилка / успіх | `#e5484d` / `#30a46c` |
| Кольори карток (JSON Canvas) | 1 `#ff6b6b` червоний, 2 `#ffa94d` помаранчевий, 3 `#ffd43b` жовтий, 4 `#51cf66` зелений, 5 `#4dabf7` синій, 6 `#b197fc` фіолетовий; у меню картки ще «Акцент» `#0a84ff`, «Рожевий» `#ff6fae`, «Сірий» `#8e8e93`, «Без кольору» |
| Кольорова картка | легкий тон кольору (≈14 %) на тлі + помітніша рамка |

### Форма й розміри
- Радіуси: вікно 22, панель 18, кнопка/контрол 12, внутрішнє 8, «капсула» (пігулки, док) 999.
- Бічна панель 248 px; шапка 56 px; ширина рядка тексту в редакторі 720 px.
- Мінімальне вікно 900 × 600.

### Шрифти
- Інтерфейс і текст: **Inter** (запасні — системні). Моноширинний: `ui-monospace / SF Mono / Cascadia Code / Consolas`.
- Розміри інтерфейсу: 12 / 13 / 14 px; текст нотатки 16 px, міжрядковий 1.6; заголовки H1 1.9em … H6 0.92em.
- Шрифти карток (вибір користувача): Як у темі, Системний, Із засічками, Округлий, Моноширинний, Друкарська машинка, Рукописний.
- Текст карток: «Авторозмір» (за площею картки) або фіксований розмір (у налаштуваннях і для кожної картки окремо).

### Рух
- Пружини як в iOS/macOS, задані через CSS `linear()`: **smooth** (470 мс, без перельоту), **snappy** (320 мс, ледь помітний переліт), **bouncy** (500 мс, помітний «відскок» для появи).
- Поява меню/діалогів — bouncy; закриття — швидше (snappy / 300 мс).
- Колесо миші на полотні — плавне доїжджання (~120 мс, експоненційне).
- `prefers-reduced-motion`: анімації вимикаються або стають кроковими.

## 3. Структура вікна

```
┌───────────────┬───────────────────────────────────────────────────────┬────────────────┐
│ [Пошук Ctrl+K]│ Назва сховища  [Полотно|Нотатки]            [🔗]  ─ □ ×│                │
│ ФАЙЛИ         ├───────────────────────────────────────────────────────┤  Зворотні      │
│  дерево папок │ [вкладка][вкладка]                                    │  посилання     │
│  і нотаток    │                                                       │  (права панель,│
│ ТЕГИ          │        редактор нотатки  АБО  полотно                 │   вмикається   │
│  #тег 2 #ще 1 │                                                       │   кнопкою 🔗)  │
│               │                                                       │                │
│ Мої нотатки ⚙ │            [ Картка | Малювати | Граф | Рамка | − 100% + ]  ← док      │
└───────────────┴───────────────────────────────────────────────────────┴────────────────┘
```

- **Бічна панель (ліва, скло):** поле пошуку (Ctrl+K / Ctrl+Space; `#тег` шукає за тегом); «Файли» — дерево з папками, значок типу для не-нотаток («полотно», «png»…); «Теги» — пігулки з лічильником; внизу — **назва сховища (кнопка: відкриває картку «Змінити папку сховища?»)**, стан збереження («● Збережено») і шестерня налаштувань.
- **Шапка:** назва сховища; перемикач **Полотно / Нотатки** (сегментований, з «повзунком», що переїжджає); праворуч — кнопка 🔗 «Зворотні посилання»; ще правіше — системні кнопки вікна (прозорий оверлей Windows).
- **Вкладки:** як у браузері; одна порожня вкладка на старті ховається.
- **Головна область:** редактор нотатки (живий перегляд) або полотно або граф.
- **Права панель «Зворотні посилання»:** хто посилається на відкриту нотатку, з рядком контексту.
- **Док (плаваюча скляна капсула внизу по центру):** на полотні — Картка, Малювати, Граф, Рамка, масштаб (− 100 % +); у режимі «Нотатки» — лише Нотатка, Граф (інструменти полотна сховані). Коли середня частина вужча за 640 px — лише іконки.

## 4. Екрани й елементи

### Старт / порожній стан
«Нотатку не відкрито / Оберіть нотатку зліва або створіть нову.» + синя кнопка **«Створити нотатку · Ctrl+N»** + до 5 «Нещодавніх» нотаток кнопками.

### Редактор (живий перегляд, як в Obsidian)
- Розмітка (`#`, `**`, `[[ ]]`, `>`) ховається на всіх рядках, крім того, де курсор; коли редактор не у фокусі — схована всюди.
- Списки — крапки «•»; завдання `- [ ]` — справжні чекбокси (клік ставить `[x]` у файлі).
- Цитати — з рискою ліворуч; таблиці — справжня таблиця (клік повертає сирий Markdown).
- Посилання `[[Нотатка]]` — сині; Ctrl+клік відкриває; на відсутню нотатку — пунктирне підкреслення.
- Теги `#тег` — пігулки.

### Полотно
- Нескінченна площина з крапковою сіткою (крок 16–33 px на екрані за будь-якого масштабу, суто декоративна).
- **Картки:** текстова картка (Markdown усередині), картка-нотатка (показує вміст файлу; над нею підпис з назвою, якщо назва не повторює заголовок), картка-зображення (вставка Ctrl+V), посилання. **Рамка** — пунктирна група з підписом.
- Теги картки — дрібно в правому нижньому куті (лише ті, яких немає в тексті).
- Довгий вміст — тонка смуга прокрутки + затухання знизу.
- **Зв'язки:** криві зі стрілкою від боку до боку; підпис — пігулка посередині. Тягнете з «+» на боці картки → картка-ціль обводиться синім, точка входу світиться; повтор того самого шляху не створюється (сірий пунктир).
- **Виділення:** клік; Ctrl+клік додає/прибирає; Ctrl+перетягування по порожньому — рамка виділення. Виділена картка — синя рамка.
- **Малювання:** режим олівця поверх полотна.
- **Масштаб:** Ctrl+колесо, кнопки в доці; колесо — плавна прокрутка.

### Меню картки (правий клік / Shift+F10) — скляний діалог 268 px
1. Назва картки (дрібно)
2. **Колір** — 9 кружечків
3. Дублювати (Ctrl+D) · Копіювати текст · Відкрити в «Нотатки»
4. На передній план · На задній план · Закріпити позицію · З'єднати з… · Від'єднати зв'язки (з лічильником)
5. **Вигляд картки ›** — згорнутий розділ (відкривається лише для цього меню): тип картки (Звичайна, Заголовок, ЗАГЛАВНІ, Банер, Цитата, Список — плитки з мініатюрою), вирівнювання назви (ліворуч/центр/праворуч), розмір тексту (Авто + крокова капсула − 15 px + і повзунок), шрифт (плитки «Aa» з назвою), фото (додати/замінити/прибрати, заповнити/вмістити, затемнення), розмір Ш × В
6. Прибрати тег #… (для кожного тегу)
7. **Видалити** (червоним, у кінці; другий клік підтверджує)

Для кількох виділених карток — те саме, дії йдуть на всі («Вибрано карток: N»).

### Інші меню
- **Правий клік по файлу/папці:** Відкрити в новій вкладці, Перейменувати…, Перемістити до…, Видалити; для папки — Нова нотатка, Нова папка…, Нове полотно.
- **Правий клік по порожньому місцю зліва:** Нова нотатка, Нова папка…, Нове полотно, Новий тег…, Відкрити інше сховище….
- **Правий клік по тегу:** Показати нотатки з тегом, Зберігати всюди (тег видно в кожному сховищі, позначка-глобус), Прибрати тег.
- Тег можна **перетягнути** на нотатку в дереві або на картку полотна.
- Наведення на тег — праворуч «вискакує» скляна бульбашка × (прибрати тег з усіх нотаток).

### Повідомлення «Скасувати» (для дій, яких не бере Ctrl+Z на місці)
Скляна капсула над доком: кружок-відлік 10 с (спорожнюється з кінця, з числом), текст («„План“ переміщено в кошик»), кнопка **«Скасувати Ctrl+Z»**. Пауза при наведенні/фокусі. Видалення в кошик, прибирання тегу з усіх нотаток, видалення плагіна — виконуються одразу, без «Ви впевнені?», але з цією можливістю скасувати.

### Картка «Змінити папку сховища?»
Пружинить угору від назви сховища внизу: заголовок, повний шлях (моноширинним), пояснення, «Скасувати» / «Обрати папку…».

### Налаштування (Ctrl+,) — скляний діалог 920 × 640
Ліворуч розділи групами: **Застосунок** — Вигляд (відкривається першим), Щоденні нотатки, Шаблони; **Підключення** — Claude; **Плагіни** — налаштування плагінів, Плагіни спільноти (останнім).
- «Вигляд»: Зменшити прозорість (перемикач), Авторозмір тексту (перемикач), Шрифт нотаток (плитки), Розмір тексту карток (капсула − N px + і повзунок).
- **Перемикач** — НЕ айфонівський: прямокутна доріжка (радіус 9), квадратний бігунок; увімкнений — колір акценту і галочка на бігунку.
- «Claude»: пояснення приватності, «Підключити до Claude Desktop», команда для Claude Code з «Копіювати».
- Вужче 640 px (масштаб 400 %): розділи — рядком угорі, налаштування під назвами.

### Палітра команд (Ctrl+P)
Скляне вікно вгорі по центру з полем «Знайти команду…» і списком; праворуч від команд — їхні гарячі клавіші.

### Галактика
Третій вид у перемикачі шапки (Полотно / Нотатки / **Галактика**): нотатки й текстові картки полотен — зірки в 3D на темному тлі вікна (картка підписана «Картка · <полотно>», «Відкрити» показує її на полотні). Розкладка «Диском» (спіраль з трьох рукавів за головним тегом), «Папками» або «Тегами» (туманності-кластери з підписами). Розмір зірки — кількість зв'язків, яскравість — свіжість, колір — група. Миша: перетягування — обертати, Shift / права кнопка — зсунути, колесо — зум до курсора, клік — вибрати (картка «Нотатка · група / назва / N зв'язків · змінено … / Відкрити · Enter»), подвійний клік — відкрити. Клавіатура: стрілки, Enter, F (фокус: зв'язки лініями #6cb4ff, решта приглушена, панель «Фокус» праворуч), Escape. Док галактики — скляна капсула внизу: «Ракурс: Зверху / Під кутом / З ребра», «Групувати: Диском / Папками / Тегами», «Скинути», − % +. У режимі «Зменшити прозорість» і при зменшеному русі — без світіння й обертання.

### Граф
Вузли-кружечки з назвами нотаток і лінії-посилання; клік відкриває нотатку.

## 7. Правила, яких дизайн має дотримуватись
- **Доступність WCAG 2.2 AA:** справжні `<button>`/`<input>`; кнопки-іконки мають назву (`aria-label`); контраст тексту ≥ 4,5 : 1, елементів керування ≥ 3 : 1; видима рамка фокусу (синя, 2 px); цілі ≥ 24 × 24 px; усе доступне з клавіатури; меню й діалоги закриваються Escape і повертають фокус; важливе оголошується для програм читання екрана.
- **Вміст важливіший за хром:** нових яскравих акцентів без потреби не додаємо; одна головна дія на екран.
- **Нічого не нищити:** файли користувача — звичайний Markdown/JSON Canvas; поля, яких застосунок не знає, зберігаються.
- **Продуктивність:** сховище на 10 000 нотаток має відкриватись за 2–3 с; полотно — 60 кадрів/с; скло й тіні — помірно.
- **Без UI-бібліотек і без нових важких залежностей.**

## 8. Що відомо як недороблене / відкрите
- Світлої теми немає (питання відкрите).
- Збірка для macOS ще не зроблена (лише Windows-інсталятор).
- Великі картки-нотатки мають трохи більший текст за малі (так працює «Авторозмір»).
- Розділення екрана на кілька панелей, попередній перегляд посилань при наведенні, вбудовані `![[…]]` у редакторі — ще немає.

## 9. Як питати (шаблон для чату)

```
Ось контекст мого застосунку (файл DESIGN_BRIEF.md) і скриншот.
```
